Core Philosophy

Engineered Around Four Fundamental Commitments

Rather than locking your curated library behind closed proprietary clouds or treating academic PDFs as opaque text dumps, Zocrates respects how scholars read, verify, and think.

🏛️ Why "Zocrates"?

The name Zocrates is a portmanteau of Zotero and Socrates, honoring the classical philosopher renowned for dialectical inquiry and intellectual honesty. Rather than acting as an ungrounded oracle, Zocrates embodies the Socratic method by actively questioning literature, probing research gaps, and demanding verifiable evidence for every claim. It transforms your personal Zotero collection from a passive repository into an inquisitive, rigorous dialogue partner.

🧭

1. Multiple Ways to Work

Use Zocrates as an embedded split-pane companion inside Zotero, as an open Markdown knowledge bundle engine on your filesystem, or as a local Model Context Protocol (MCP) server for external assistants like Claude Desktop, Cursor, Pi & others (any application that supports MCP).

🛡️

2. Local-First & Hardened by Design

Your search indices, converted Markdown bundles, strictly local deterministic paper relation graphs, and chat histories live 100% on your machine—fortified by 256-bit loopback auth, strict CORS isolation, safe DOM sanitization, and encrypted credential storage.

⚖️

3. Scholarly Rigor & Verifiable Truth

Every synthesized claim is anchored in exact document passages, checked on a per-occurrence basis by fast AI decision verifiers, and backed by Two-Tier Source reporting so zero evaluated literature is ever silently dropped.

🔭

4. End-to-End Scholarly Experience

From native KaTeX mathematics, inline extracted paper figures, and user-curated long-term memory via native Zotero notes to autonomous online literature discovery across OpenAlex, Crossref, and Unpaywall with one-click Zotero collection import.

Quick Installation

Install in Minutes from GitHub

No manual Python environment setup or command-line scripts required. Zocrates installs as a standard Zotero 10+ extension and provisions its hermetic runtime automatically.

1

Download Zocrates from GitHub Releases

Download the latest zocrates.xpi release file from the official GitHub Releases page. In Zotero 10+, open Tools → Plugins, click the gear icon ⚙️, and select Install Plugin From File…

2

Automatic Background Provisioning

On first launch, Zocrates automatically provisions an isolated, per-profile runtime under <zotero-data>/zocrates-data/ with pinned dependencies—and shuts down cleanly whenever Zotero closes.

3

Connect Your Preferred AI Provider

Open Zotero Settings → Zocrates. Enter your OpenRouter API key (recommended for instant frontier models) or point to a local Ollama / vLLM server. Tailor your persistent User Research Profile and start chatting!
